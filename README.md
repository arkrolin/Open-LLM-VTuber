# Open-LLM-VTuber 临时项目
该项是时源自 Open-LLM-VTuber 的一个临时项目，旨在将我一些想要添加个功能加入其中，由于原项目V1版本的开发已经暂停且不再受理PR，所以我就自己开了个项目来添加功能。
原项目地址：<https://github.com/Open-LLM-VTuber/Open-LLM-VTuber>

## 已添加功能
### 对index-tts2的api支持
添加对index-tts2的api支持，允许用户使用index-tts2进行文本到语音的转换，其实当前个人认为最好的T2S引擎,虽然它的部署比较麻烦，但效果真的很好，所以我就添加了对它的支持。如果需要部署使用需要8GB+显存。
### 角色记忆的保存
现在，角色可以跨对话保存记忆力，再一定轮数的对话后(默认10轮)，角色会自动总结对话内容并保存到记忆中，这样角色就可以在后续的对话中使用这些记忆来更好地理解用户的需求和提供更个性化的回复。
也可以使用`/memory`或`/mem`来要求角色保存记忆。
角色会默认使用最近3天的记忆总结内容，用户可对记忆markdown文件进行编辑。
同时修改提示词，强调要求使用现有记忆。
